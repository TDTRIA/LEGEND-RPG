Current Project Status

Production main · LEGEND: The Awakening v0.27.0

The current build includes the road-first Dead Lantern opening, Ashmere town services, a five-stage Old Road, turn-based combat and progression, the Bell Cellar, and substantial Greyfen Marsh Path content. The first three-town release is not complete; Ironpass is not playable on main.

Current stabilization: the latest main regression run reported 207 passed, 3 failed, and 1 skipped. The syntax check passed; the live deployment smoke step was skipped because of the test failures. The immediate priority is to make every scene readable without covering the environment art, fix the outstanding portrait overlap, and restore a clean test run.

What comes next

Stabilize the shared world shell, then finish the Greyfen town/economy/story loop before expanding to Ironpass. New features must preserve the current save and combat systems and ship as complete playable slices.
