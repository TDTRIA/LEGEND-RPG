# LEGEND title UI vector kit

These original vector pieces came from the CodeRabbit-generated LEGEND-UI-starter.zip handoff supplied on 2026-11-08. They are decorative presentation assets only: all titles, labels, button text, states, accessibility names and actions are supplied at runtime by the production UI.

- legend-frame-corner-v1.svg is designed to be placed in four corners and flipped/rotated, not stretched.
- legend-button-normal-v1.svg, legend-button-selected-v1.svg and legend-button-disabled-v1.svg are label-free button backgrounds.
- legend-divider-v1.svg is a horizontal decorative separator.

Do not bake text or game values into these vectors. Keep the DOM buttons as semantic keyboard/touch targets until Phaser parity is tested on both desktop and mobile. The full rectangular starter frame is intentionally not used because it stretches unless implemented as a proper nine-slice.
