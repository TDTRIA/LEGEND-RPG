Welcome to the Recovered Build

Hey everyone,

Welcome to The Recovered Build Dispatch, the newsletter for Legend - Recovered Build.

LEGEND started as the first game I ever came up with: a fantasy RPG written completely in Windows Batch. The recovered version had accounts, saving, combat, shops, enemy drops, skills, banking, quests, and a boss named Lacoyx.

Years later, I found the old build again and decided to remake it as a playable HTML5 browser RPG.

That remake has now become Legend - Recovered Build, a dark fantasy text RPG about Ashmere, The First Road, the Lost Build, recovered memories, and a world that seems to remember it used to be made of code.

The current playable version is:

Recovered Build v0.5 - The First Road

This update adds

  • The First Road opening route
  • Road Tokens as an early objective
  • Ashmere Inn
  • Camp Supplies
  • steadier weapon damage
  • enemy traits
  • mastery perks
  • clearer quest tracking
  • mobile polish
  • named NPCs and dialogue
  • the first real questline, The Bell That Rang Once

You can play the current build here:

Recovered Build v0.5 — The First Road

This project is still early, but it is already turning into something much bigger than a simple remake. The goal is to preserve the spirit of the original batch game while building the version it could have become.

Future updates will include more quests, more routes, stronger NPCs, better combat, crafting, more lore, more bosses, and eventually real art.

Thanks for following the project this early.

The world of LEGEND was once larger.

Now it is starting to remember.

— Keegan
